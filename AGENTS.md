# AGENTS.md — laim-baskets-adapter

Репозиторий одной ноды Sber DS. Правила проекта LAIM (`AGENTS.md` репозитория
`laim`) действуют целиком; здесь — то, что специфично для репозитория ноды.

- **Нода самодостаточна.** Никаких импортов извне каталога; `descriptor.json`
  перечисляет все исходники в `sourceFiles` (закреплено тестом). База платформы —
  `py312-simple`: синтаксис и stdlib новее Python 3.12 не использовать.
- **Ветки.** `test` — замороженный снимок аудированной версии, не чинить.
  Рабочая ветка — `km-val-report`. Каждая правка — тематическая ветка `fix/*`
  или `chore/*` от рабочей, один коммит — одна находка или задача, влитие
  через `--no-ff`. `main` не используется.
- **Гейт качества.** CI (`.github/workflows/ci.yml`: ruff, pytest, контракт
  sourceFiles) обязан быть зелёным до влития. Перед объявлением версии
  прод-сборкой — допуск-ревью `/laim-code-review` из репозитория `laim`.
- **TDD.** Сначала тест, воспроизводящий дефект или контракт, затем минимальная
  правка. Тесты не ослаблять и не пропускать ради зелёного прогона.
- **README — контракт деплоя.** Структура по `docs/README-template.md` из
  `laim`: любое изменение поведения (порт, настройка, деградация, reason_code)
  отражается в README тем же коммитом.
- **Сообщения коммитов** на русском: строка «что сделано» до 72 символов, в теле —
  зачем; номер находки аудита (LAIM-NNNN), если правка закрывает её.
- **Снимок в `laim`.** Готовая версия переносится в `laim/monitoring/laim-baskets-adapter`
  отдельной синхронизацией с обновлением строки `MANIFEST.md`.
