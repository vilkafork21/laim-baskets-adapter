# AGENTS.md — laim-baskets-adapter

- Этот private-репозиторий — источник истины для ноды `laim-baskets-adapter`.
- Здесь хранится только одна нода; разработка идёт в отдельных тематических ветках,
  изменения коммитятся и публикуются именно сюда.
- `test` основан на audited snapshot `902d9ee370d`; `km-val-report` — на feature snapshot
  `2ba7cc38ae6`. Исходные снимки зафиксированы отдельными коммитами и не переписываются.
- Перенос готовой версии в монорепозиторий LAIM выполняется только отдельной явной
  синхронизацией с обновлением его `MANIFEST.md` и связанных контрактов.
- Нода остаётся самодостаточной и совместимой с Python 3.12; импортов из соседних нод
  или `monitoring/shared` быть не должно.
- Изменение портов или контракта требует согласованного изменения `descriptor.json`,
  потребителей и тестов.
- Перед правкой запускается baseline; после неё — тесты ноды и `ruff check` изменённых файлов.
- Секреты, `.env`, credentials и данные прогонов не коммитятся.
- Коммитить и пушить новые изменения можно только по явной просьбе пользователя.
